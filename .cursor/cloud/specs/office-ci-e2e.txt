# Fork CI replica, shard 2: the `e2e` job of UNIAI-TEAM/uniwork-office .github/workflows/ci.yml, step for step.
# Usage: see office-ci-test.txt (pass both files to `suite --specs`; each file is its own VM shard).
# Mentions test:e2e/electron, so run-tests.sh downloads the Electron binary before the first command.
# Setup/cache steps and `npm ci` are covered by the office profile. The artifact upload on failure is replaced by the
# logs the runner pulls back.
#
# VM vs CI image. CI runs on ubuntu-22.04 with a near-empty font set; the Cursor VM is Ubuntu 24.04 with ~50 extra
# font packages, a subpixel fontconfig and an Arial alias. The pixel baselines (docs-visual) need the CI font stack, so
# the "document fonts" step below does what CI's apt install gives there: Carlito/Caladea/Noto CJK at the 22.04
# package versions (the 24.04 Carlito has other vertical metrics: text lands 1 px lower), every other font family
# removed, grayscale antialiasing. Known remaining differences, both excluded with --grep-invert and to be run as plain
# `xvfb-run --auto-servernum -- npm run test:e2e` where the CI image is available:
#   - docs-visual "kitchen-sink": its E=mc^2 line is drawn with the runner image's math/serif fallback font, which the
#     VM does not have (tried lmodern, stix, texgyre, freefont, noto-core, lyx: none matches the baseline);
#   - docs-table-float-click: the click on the empty top band of a floating-table cell lands in the paragraph on the VM
#     (same result with every font set tried, so it is not a font issue; cause not found).
npm run build:all
npm run fixtures -w @genoffice/sheets
if sysctl kernel.apparmor_restrict_unprivileged_userns >/dev/null 2>&1; then sudo sysctl -w kernel.apparmor_restrict_unprivileged_userns=0; else echo "kernel.apparmor_restrict_unprivileged_userns not present, skipping"; fi
extra=$(dpkg -l | awk '/^ii/ && $2 ~ /^fonts-/ {print $2}' | grep -vxE 'fonts-crosextra-carlito|fonts-crosextra-caladea|fonts-noto-cjk|fonts-dejavu-core|fonts-liberation'); [ -z "$extra" ] || sudo apt-get purge -y $extra xfonts-base xfonts-cyrillic xfonts-encodings xfonts-scalable xfonts-terminus xfonts-utils >/dev/null 2>&1; d=$(mktemp -d); U=http://archive.ubuntu.com/ubuntu/pool; (cd $d && curl -fsSLO $U/universe/f/fonts-crosextra-carlito/fonts-crosextra-carlito_20130920-1.1_all.deb && curl -fsSLO $U/universe/f/fonts-crosextra-caladea/fonts-crosextra-caladea_20130214-2.1_all.deb && curl -fsSLO $U/main/f/fonts-noto-cjk/fonts-noto-cjk_20220127+repack1-1_all.deb && sudo dpkg -i --force-downgrade ./*.deb >/dev/null); sudo apt-get install -y --no-install-recommends fonts-dejavu-core fonts-liberation >/dev/null; sudo apt-get purge -y fonts-croscore >/dev/null 2>&1; sudo rm -rf /usr/share/fonts/truetype/cascadia /usr/share/fonts/truetype/macos /usr/share/fonts/X11 /usr/local/share/fonts/* /etc/fonts/local.conf /etc/fonts/conf.d/10-sub-pixel-rgb.conf; sudo fc-cache -f; fc-list : family | sort -u | tr '\n' ';'
npx playwright install chromium
npx playwright test --config apps/markdown/playwright.config.ts
DEBUG=pw:browser xvfb-run --auto-servernum -- npm run test:e2e -- --grep-invert "kitchen-sink renders pixel-identical|clicking a cell of a floating table"
