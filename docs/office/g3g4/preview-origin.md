# Markdown/HTML preview origin deployment

The Markdown and HTML preview is an untrusted document renderer. It is served
through a dedicated preview origin (`preview.<deployment-host>` in production;
a second local hostname/port such as `http://localhost:13001` in development).
The app origin is never reused to make relative links work. The iframe is
`sandbox`ed without `allow-same-origin`, and it receives no app cookie, bearer
token, clipboard, download, IPC or API bridge.

## Configuration

The Go server reads these values at startup and fails closed when one is
missing, malformed, or unsafe:

| Variable | Rule | Example |
| --- | --- | --- |
| `PREVIEW_ORIGIN` | absolute `http`/`https` origin, no path/query/fragment, and different from `FRONTEND_ORIGIN` | `https://preview.example.com` |
| `PREVIEW_CAPABILITY_SECRET` | at least 32 random characters; rotate independently from `JWT_SECRET` | `base64-or-random-secret` |
| `PREVIEW_ASSET_TTL` | positive duration, at most one hour | `10m` |
| `PREVIEW_ASSET_MAX_BYTES` | positive integer byte ceiling applied by the broker | `10485760` |

The preview listener may be a separate reverse-proxy virtual host that routes
to the same Go process. In an on-premise installation, provision a second DNS
name and certificate; a second port on the same host is only suitable for
local development. Do not put `PREVIEW_ORIGIN` behind a redirect: the broker
returns final bytes directly and never follows a caller-controlled URL.

For the production Helm deployment, create the `uniwork-preview` Secret with
the random `PREVIEW_CAPABILITY_SECRET` key and keep it out of the ConfigMap;
the backend chart injects that key at boot. The edge `ApisixTls` object must
bind both `uniwork.unicomhub.com` and `preview.unicomhub.com` to the certificate.
For `docker-compose.prod.yml`, set `PREVIEW_ORIGIN` and a 32-character-or-
longer `PREVIEW_CAPABILITY_SECRET` in the private `.env` file before starting
the server; startup fails closed if either value is missing or invalid.

## Proxy and headers

Route `POST /api/v1/documents/{documentID}/preview/scopes` through the app
origin. It requires the normal session and Documents view permission. Route
`GET /api/v1/preview/assets/{capability}/{assetID}` on the preview origin
without cookie authentication. The capability is opaque, short lived,
scoped to one user, document, render job and explicit asset ids. Every byte
read calls the Documents service again, so a revoke or membership change
stops the next request. Unknown, expired, replayed, foreign-document,
traversal and absolute-URL requests all answer the same `404 not_found`.

The broker response must preserve these headers:

```
Content-Type: <manifest media type>
Content-Disposition: inline
Cache-Control: no-store
X-Content-Type-Options: nosniff
Content-Security-Policy: default-src 'none'; sandbox
Referrer-Policy: no-referrer
Cross-Origin-Resource-Policy: cross-origin
Access-Control-Allow-Origin: *
```

The HTML frame's CSP is stricter and is generated by the web preview host:
`default-src 'none'`; `connect-src 'none'`; no frames/forms/base/object/
workers; `script-src 'none'` unless an explicit trusted capability is present;
images, media, fonts and styles may use only the checked preview origin and
safe inline data. Never add `allow-same-origin` or wildcard network sources.

## Broker contract

The scope request contains `{job_id, assets:[{key, asset_id}]}`. `key` is a
canonical package-relative manifest key and is used only to map the returned
URL; `asset_id` is the opaque Documents id. The response is:

```
{ "origin": "https://preview.example.com",
  "expires_at": "2026-09-30T12:00:00Z",
  "assets": [{ "key": "assets/logo.png", "asset_id": "01…", "url": "https://preview.example.com/api/v1/preview/assets/<cap>/<id>" }] }
```

No storage key, filesystem path, arbitrary URL, API token or redirect is
returned. The web renderer rewrites only the preview copy; source Markdown or
HTML is left byte-for-byte unchanged. If the scope endpoint or policy is
unavailable, the view reports the typed `preview unavailable` state and never
falls back to the app origin.

## Fault table

| Symptom | Safe result | Operator check |
| --- | --- | --- |
| Missing/invalid origin or secret | Server refuses to start; UI shows preview unavailable | Correct env and restart; do not copy the app origin |
| Scope returns 404 | Frame renders without the missing asset; no existence detail leaks | Check Documents membership/ACL and manifest id |
| Scope expired/revoked | Asset request is 404 and the frame is blanked on the next render | Mint a fresh scope; inspect clock skew and TTL |
| CSP or sandbox header missing | Deployment is unsafe and must be rolled back | Compare proxy headers with the contract above |
| Redirect, traversal or absolute URL observed | Broker answers 404 and emits no redirect/fetch | Inspect the authored manifest; never whitelist the URL |
| Foreign document or non-member id | Same 404 as a missing asset | Verify tenant/workspace ACL through Documents service |
