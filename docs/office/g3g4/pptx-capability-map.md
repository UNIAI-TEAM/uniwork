## Command boundary

`PptxToolbar` only dispatches command ids. Save calls the shared `OfficeSaveCoordinatorLike.save()` entry point; it never calls `host.write`, uploads bytes, or commits a version. Shape and image gestures call `host:slides-edit-transform` through the typed `OfficeHost.ipc` channel. When that channel is absent, the command is disabled with its reason; no element style is mutated to claim a file edit. Presenter and fullscreen are views over the same `EditorHandle`, so selection, dirty state, and session identity remain intact.

## Error and recovery states

The root `EditorSlot` renders typed `error`, `password-cancel`, and `unsupported` states and does not mount `PptxEditor` or expose Save for those states. A subsequent valid open can mount the same slot without an application reload.
