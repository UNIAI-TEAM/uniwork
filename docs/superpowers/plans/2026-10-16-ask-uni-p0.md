# Hỏi UNI v2 — P0 Sửa nền: Implementation Plan

> **Trạng thái:** in-progress — Task 1–10 đã làm trên nhánh feature/UNI-1818-hoi-uni-v2-p0-sua-nen-injection-tim-nguo; còn Task 11 bước 2–3 (chạy eval live, ghi mức nền) do người làm. Issue UNI-1818 (sub-issue UNI-1819…1823).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sửa các lỗi nền của Hỏi UNI hiện tại (giao diện, chống prompt injection, tìm kiếm, i18n, cấu hình production) và dựng bộ câu hỏi đánh giá, để P1 (agent) có nền đo được.

**Architecture:** Giữ luồng một lượt hỏi của `AskUNIService.Ask` và prompt `copilot_answer@1`. Server vá cách bọc nội dung không tin cậy, thêm cột `notice` cho câu trả lời "không có nguồn", cải thiện tìm nguồn (bỏ dấu, mã task, tài liệu, câu hỏi tiếp theo). Client sửa panel, store, hook. Bộ đánh giá là test Go chạy với provider fake trong CI và chạy tay với model thật.

**Tech Stack:** Go (Chi, pgx, sqlc), PostgreSQL, Next.js + React Query + Zustand + zod, i18next, vitest.

**Spec:** `docs/superpowers/specs/2026-10-16-ask-uni-agent-design.md` (§2, §6.3, §6.10, §7 P0, §8, §6.7 phần cấu hình production).
