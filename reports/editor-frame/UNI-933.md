## What changed
Shared layer:
- `packages/ui/styles/tokens.css`: `--office-band` (#f5f5f6 / dark #1a1a1a) and `--office-canvas` (#e8e8ea / dark
  #0b0b0b), declared in `:root` and `.dark`, mapped as `bg-office-band` / `bg-office-canvas`; `cn()` knows them.
- `ribbon/office-ribbon.tsx`, `ribbon-tab-row.tsx`: the ribbon root is ONE band (grey surface, one bottom border,
  font-sans); the tab row and the group row share it; body 96px; collapse ⌃ far right (unchanged behaviour).
- `ribbon/ribbon-group.tsx`, `ribbon-item.tsx`, new `ribbon-gallery.tsx`, `ribbon-menu.tsx`, `layout.ts`, `types.ts`:
  inset separators, caption bottom-centre, launcher bottom-right; large = 32px icon + 2-line label (large split = Word
  Paste: icon on top, label + ▾ underneath); small rows / icon buttons 24px (44px on coarse pointers); combos 140px
  default, 56px floor; gallery = one bordered box of specimen + name cards with a more column (`sample` field);
  a `custom` item with `size: "icon"` packs into icon strip rows. 924 W-FIX-M/N/O kept (panel wrap/height tests green).
- New `office/frame/`: `OfficeFrame` (ribbon, subbar, rail | canvas | aside, bottom, statusBar; absent slots render no
  row) + `OfficeStatusBar` (one 28px row, start/end/help) + `OfficeStatusZoom`; i18n `office.status.*` (en + vi).
- `office-shell.tsx` (no `p-3` around the editor), `editor-slot.tsx` (no card once the editor is mounted; messages keep
  padding), `documents/document-workspace.tsx` + `document-file-view.tsx` (`usesOfficeEditor`: no gutter/padding when
  the Office editor replaces the file view, so the ribbon attaches directly under the page header),
  `apps/web/platform/office/editor-host.tsx` (unbound-format alert keeps its own margin).
- Desktop: `apps/office-desktop/renderer/office/open-document.tsx` mounts `OfficeShell` + `DocxEditor` directly, so it
  gets the same frame with no change (typecheck below).

DOCX adoption:
- `docx-editor.tsx`: ready state = `OfficeFrame` (ribbon, find dock, grey canvas with ruler + pages, status bar).
- `docx/status/status-bar.tsx`: one `OfficeStatusBar` row + `OfficeStatusZoom`; help "?" moved from the floating dock
  over the canvas into the status bar help slot (Mod+/ still opens it). Canvas grey = `--office-canvas`.
- `docx/toolbar/**` (data only): Clipboard = large Paste + Cut/Copy/Format painter icon column (painter moved from
  Font); Font = family 148px + size field, change case, clear / B I U S x₂ x² colour highlight, all icons; Lists merged
  into Paragraph (lists/indent row, 4 alignment toggles + spacing row); Styles = in-ribbon gallery with Word's
  "AaBbCcDd" specimen; contextual table/picture alignment + rotate as icons.

Lanes: `reports/editor-frame/ADOPTION.md` is the checklist for 925/926/927/928 (they adapt their formats after merge).
