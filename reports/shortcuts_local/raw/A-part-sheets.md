# A-part-sheets — fork `apps/sheets` shortcut inventory

Fork checkout: `uniwork-office` @ d999b8801 (read-only). CSV: `A-part-sheets.csv` (144 rows, 13 columns, RFC4180). Surfaces: `web-frame` = renderer code (runs in the module frame and in the Electron renderer), `desktop-shell` = Electron main-process menu (`apps/sheets/src/main/sheets-main.ts`, `packages/electron-utils/src/app-menu.ts`).

## Important limitation

`node_modules` is not installed in the fork checkout, so **no Univer source was readable** (`@univerjs/*` ^0.25.1, `apps/sheets/package.json:37-51`). Univer's own default shortcuts (undo/redo, find, Ctrl+Enter, F4, Esc, plain arrows, QuickSum, SmartToggleFilter, zoom Ctrl+0/=/-) are listed in the CSV only where the fork's comments, e2e specs or its own overrides prove they exist; those rows carry `source = univer default (... source NOT installed)`, `ime_safe/altgr_ok = unknown`, `confidence = medium/low`, with the evidence in `notes`. The complete default Univer keymap is therefore NOT inventoried; it needs a pass with `npm ci` done (`@univerjs/sheets-ui` shortcuts/*.shortcut.ts, `@univerjs/ui` shortcut service).

## Where Sheets shortcuts are defined — there is no single place

Four independent layers (all hand-written, none generated from another):

| Layer | File | What it holds |
| --- | --- | --- |
| 1. App window handler + pure table | `apps/sheets/src/renderer/global-shortcuts.ts` (`BINDINGS` :68-163, `resolveGlobalShortcut` :252) driven by the `keydown` listener `ExcelShell.tsx:791-822`; number-format/border chords in `excel-format-shortcuts.ts` | ~35 chords that dispatch ribbon/dialog commands; table is data (`code`, `chord`, `gate`, `action`), unit-testable |
| 2. Univer `IShortcutService` registrations | `excel-shortcuts.ts` (:367-509), `excel-jump-nav.ts` (:497-522), `format-painter.ts` (:91-95) | keys that must live inside Univer's dispatcher so its focus/editor preconditions (`whenSheetEditorFocused`, …) apply; matched by raw keyCode |
| 3. Window capture interceptor | `ExcelShell.tsx:830-837` + `clear-selection-keyboard.ts` | Delete/Backspace over a selection (beats Univer's Backspace binding) |
| 4. Electron menu | `sheets-main.ts:4682-4764` + `packages/electron-utils/src/app-menu.ts` | Open/Save/SaveAs/Print/Close/Undo/Redo accelerators and Cut/Copy/Paste/SelectAll roles; forwarded to the renderer via `sendMenuAction` -> `onMenuAction` (App.tsx:~3318) |

Plus ~40 per-dialog/per-panel `onKeyDown` handlers (Enter/Esc), listed individually in the CSV.

## Structural findings

1. **No shortcut help dialog and no shared table.** `grep -rniE "shortcut|keyboard|hotkey" apps/sheets/docs` returns nothing; there is no `ShortcutsDialog` in `apps/sheets/src/renderer` (contrast `apps/docs`, which has `shortcuts.ts` + `ShortcutsDialog.tsx`).
2. **Key hints are hand-written and not derived from the handler tables.** Only these exist: `platformShortcuts('⇧⌘S')` (ExcelShell.tsx:932), `data-tip-kbd` / inline text for Format Cells ⌘1 (:4028,:4032), Insert Cells ⇧⌘= (:4066), Delete Cells ⌘- (:4074), Go To ⌘G (:4189), Filter "Toggle ⇧⌘L" (:3155 via `i18n/app/en.ts:1146`), plus i18n strings `Save (⌘S)`, `Open Workbook (⌘O)`, `Go To (⌘G)` (`en.ts:669,678,129`). `platformShortcuts` (`packages/i18n/src/index.ts`, `macShortcutsToWin`) only rewrites Mac glyphs to Ctrl/Alt/Shift text; it does not read a keymap. ScreenTips (`packages/ui/src/screentip.ts`) render `data-tip-kbd` verbatim. Any change to a binding must be mirrored by hand. Hint checks: ⇧⌘= (Insert Cells) matches the registration (`excel-shortcuts.ts:456`); "Toggle ⇧⌘L" on Windows becomes `Ctrl+Shift+L`, which is Univer's own binding (not registered in the fork); on Mac the app's own filter chord is ⇧⌘F (`global-shortcuts.ts:142`) so the hint and the fork's Mac binding disagree (⇧⌘L is only Univer's).
3. **Layer conflicts / overrides (all intentional, commented).** `excel-shortcuts.ts` registers at priority 100 over Univer: Ctrl+9 / Ctrl+Shift+9 hide/unhide rows, Ctrl+0 / Ctrl+Shift+0 hide/unhide columns (displacing Univer's Ctrl+0 zoom reset), Ctrl+- Delete Cells (displacing zoom-out), Ctrl+Shift+= Insert Cells; `excel-jump-nav.ts` replaces Ctrl(+Shift)+Arrow. Window handler skips events already `defaultPrevented` to avoid double fire with Univer (Alt+= QuickSum).
4. **Duplicate meanings by key.** ⌘T on Mac = Create Table (global-shortcuts.ts:156, gate=sheet) *and* reference-cycle in the cell editor (excel-shortcuts.ts:505, whenSheetEditorActivated) — separated only by editing state. Ctrl+Shift+T = AutoSum (non-Excel on Windows) and Alt+= = AutoSum (two bindings, same action; the latter is also Univer's QuickSum). `Ctrl+Shift+M`/`Ctrl+Shift+F2` both = new threaded comment, `Ctrl+Shift+M` fires on Windows too although it is the Excel-for-Mac chord. `Ctrl+Shift+V` = paste values is not an Excel binding.
5. **`mod` is `metaKey || ctrlKey` everywhere in layer 1**, so on macOS Ctrl+<key> also fires the ⌘ chord (e.g. Ctrl+K link on Mac), and on Windows the Win/Meta key combined does too. Only the explicit `cmdMac`/`cmdCtrlMac` chords (⇧⌘F, ⌃⌘V) and the format-border chords are mac-gated.
6. **IME / composition:** none of the layer-1/2/3 handlers except the Delete/Backspace interceptor (`clear-selection-keyboard.ts:67`), the Name Box Enter (`ExcelShell.tsx:906`) and the AI ask Enter (`ai/AiSelectionAsk.tsx:131`) check `isComposing`/`keyCode 229`. Every dialog `onKeyDown` that treats Enter as "apply/commit" (≈25 sites, see CSV `ime_safe = no`) would fire on the Enter that confirms an IME candidate (relevant for Vietnamese Telex/VNI input in text inputs). Chord handlers (Ctrl+…) are practically unaffected. Univer-side dispatcher behaviour: unknown (source not installed).
7. **`event.code` vs `event.key`:** layer 1 matches the physical key (`event.code`) — comment at `excel-format-shortcuts.ts:1-2` states why (shifted digit keys report symbols). Consequence: on non-QWERTY layouts (AZERTY, Dvorak, Vietnamese layouts are QWERTY so fine) letters/punctuation chords land on the QWERTY position, not the printed legend; Excel follows the legend for some (Ctrl+Shift+&, Ctrl+Shift+_). Layer 2 uses raw keyCode (`excel-shortcuts.ts:4-8`). Only the dialog/Enter/Esc handlers use `event.key`.
8. **AltGr:** layer-1 rows with `mod` require `altKey === false` (`global-shortcuts.ts:228`), so AltGr (Ctrl+Alt) does not trigger them — except `Ctrl+Alt+V` (Paste Special, line 108) which *is* defined as mod+alt and so fires on AltGr+V. `{alt:true}` chords (Alt+=, Alt+Shift+Arrow, Alt+PageUp/Down) require mod false, so AltGr is excluded. Layer 2 (Univer): unknown.
9. **Gate bug candidate (page keys):** `PageDown`/`PageUp`/`Alt+Page*` are `gate=grid`, which does *not* test `cellEditing` (`global-shortcuts.ts:236-237`). `ExcelShell.tsx:813` calls `preventDefault()` before the command runs, then `ribbon-actions.ts:1351-1353` bails out because a cell is being edited — net effect: the keys are swallowed while typing in a cell (caret still handled by Univer's editor if it listens in capture; not verified).
10. **Keys forwarded from frame to host:** none in the sheets module itself. The menu accelerators are one-way main -> renderer (`sendSheetsMenuAction`). `packages/ui` ribbon-collapse (Ctrl+F1 / ⌥⌘R) is a window-level handler inside the frame. No `postMessage` of key events, no `before-input-event`, no `globalShortcut`, no `registerCommand` keyed to keys in `src/main` or `src/preload` (see grep evidence below). Whether the web host wraps frame keydown is outside this slice.
11. **Electron roles with implicit accelerators** (cut/copy/paste/selectAll, reload/forceReload, togglefullscreen, mac appMenu/windowMenu) are supplied by Electron, not by repo code; their exact default keys are marked `confidence=medium/low` in the CSV. `pageZoom:false` is deliberate (`sheets-main.ts:4759-4761`) so Univer owns ⌘0/⌘=/⌘-.

## Rows NOT covered (explicit gaps)

- Univer defaults not evidenced in this repo (Enter/Tab/Shift+Tab commit & move, F2 edit, Ctrl+B/I/U, Ctrl+D/R fill, Ctrl+Shift+Arrow beyond jump-nav, Home/End inside editor, Ctrl+Z inside Univer, Ctrl+P, etc.) — require Univer source.
- Univer-owned dialogs/panels (data validation, conditional formatting, filter dropdowns, sheet-tab rename) — their key handling is Univer's.
- Sheet-frame code outside `apps/sheets` (`apps/shell` tabs, `apps/uniai-pwa`, `web/`) — not in this slice.
- Mouse-modifier "shortcuts" are included only where a key modifier is read (Ctrl/Cmd+click tabs, Ctrl+drag fill, Ctrl+wheel).
