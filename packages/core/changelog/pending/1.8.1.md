# UniWork v1.8.1

## English

More reliable folder upload, cleaner statuses in Ask UNI and sturdier Chat calls

Folder upload in Documents accepts older-format Office files and says clearly when the browser cannot read a file. Ask UNI answers no longer include internal status codes, and Chat calls carry on when the server restarts.

## Improvements

- Chat calls are now saved on the server: if the server restarts mid-call, a call that is ringing or in progress can still be answered, joined and ended as usual, and the call log message still records the right outcome.

## Bug fixes

- Folder upload in Documents: valid Word, Excel and PowerPoint files in the older formats (.doc, .xls, .ppt) are no longer reported as having the wrong format. A file the browser cannot read, usually because its Windows path is too long, is now reported clearly with a tip to copy the folder to a shorter path, instead of showing a dropped connection and retrying in vain; the error dialog shows the file name first and its folder on the line below.
- Ask UNI answers show only the status name you see on screen, without an internal status code in brackets such as "To do (todo)". Asking for tasks by a status name your team created, such as "Waiting for QA", also finds the right tasks.

If folder upload says a file cannot be read on Windows, copy the folder to a shorter path and upload it again.

## Tiếng Việt

Tải thư mục ổn định hơn, Hỏi UNI ghi trạng thái gọn hơn và cuộc gọi Chat bền hơn

Tải thư mục lên Tài liệu nhận đúng tệp Office định dạng cũ và báo rõ khi trình duyệt không đọc được tệp. Câu trả lời của Hỏi UNI không còn kèm mã trạng thái nội bộ, và cuộc gọi trong Chat vẫn tiếp tục được khi máy chủ khởi động lại.

## Cải tiến

- Cuộc gọi trong Chat được lưu trên máy chủ: nếu máy chủ khởi động lại giữa chừng, cuộc gọi đang đổ chuông hoặc đang diễn ra vẫn nhận, vào và kết thúc được như bình thường, và tin nhắn nhật ký cuộc gọi vẫn ghi đúng kết quả.

## Sửa lỗi

- Tải thư mục lên Tài liệu: tệp Word, Excel, PowerPoint định dạng cũ (.doc, .xls, .ppt) hợp lệ không còn bị báo sai định dạng. Tệp mà trình duyệt không đọc được, thường do đường dẫn trên Windows quá dài, nay được báo rõ kèm gợi ý chép thư mục vào đường dẫn ngắn hơn, thay vì báo mất kết nối và thử lại vô ích; hộp thoại lỗi hiện tên tệp trước, thư mục ở dòng dưới.
- Câu trả lời của Hỏi UNI chỉ ghi tên trạng thái như trên màn hình, không còn kèm mã trạng thái nội bộ trong ngoặc như "Cần làm (todo)". Hỏi công việc theo tên trạng thái mà nhóm tự đặt, ví dụ "Chờ QA", cũng tìm đúng công việc.

Khi tải thư mục báo không đọc được tệp trên Windows, hãy chép thư mục vào một đường dẫn ngắn hơn rồi tải lại.
