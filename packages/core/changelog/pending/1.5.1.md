# UniWork v1.5.1

## English

Product menu opens each feature page, and demos use new sample data

A patch for the marketing site: each entry in the Product menu opens that feature's own page, the Watch demo button on a feature page opens the demo right there, and the demos use a new sample workspace. The Calendar demo follows the current Calendar screen.

## Improvements

- The demos on the marketing site use a new sample workspace, members and tasks in both Vietnamese and English. The Calendar demo has the same search box as the current Calendar screen and opens at 08:00.

## Bug fixes

- On the marketing site, each entry in the Product menu now opens that feature's own page, and the Watch demo button on a feature page opens the demo right there. The illustration at the end of the home page uses the product's current interface.

This patch only changes the marketing site; the UniWork app itself is unchanged.

## Tiếng Việt

Menu Sản phẩm mở đúng trang tính năng và demo dùng dữ liệu mẫu mới

Bản vá cho trang giới thiệu: mỗi mục trong menu Sản phẩm mở trang riêng của tính năng, nút Xem demo trên trang tính năng mở bản demo ngay tại trang, và các bản demo dùng một không gian làm việc mẫu mới. Demo Lịch bám theo màn hình Lịch hiện tại.

## Cải tiến

- Các bản demo trên trang giới thiệu dùng một không gian làm việc, thành viên và task mẫu mới ở cả tiếng Việt và tiếng Anh. Demo Lịch có ô tìm kiếm như màn hình Lịch hiện tại và mở sẵn ở khung 08:00.

## Sửa lỗi

- Trên trang giới thiệu, mỗi mục trong menu Sản phẩm nay mở trang riêng của tính năng đó, và nút Xem demo trên trang tính năng mở bản demo ngay tại trang. Hình minh họa cuối trang chủ dùng giao diện sản phẩm hiện tại.

Bản vá này chỉ thay đổi trang giới thiệu; ứng dụng UniWork không thay đổi.
