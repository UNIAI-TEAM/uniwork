# Bundled fonts (G2-05 PDF engine)

OFL-licensed Noto Sans faces the PDF worker embeds and subsets when an edited
document's typeface is not installed in the container (the engine image ships
no system fonts). Vietnamese coverage: Noto Sans includes the full Vietnamese
glyph set (GF `vietnamese` subset) plus Latin.
